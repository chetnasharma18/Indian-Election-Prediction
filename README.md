# Indian-Election-Prediction
Election winner prediction using Random Forest

## 📌 Project Overview

This project predicts whether a constituency will be won by BJP using a **Random Forest Classifier** based on historical election data.

---

## 🎯 Objectives

* Analyze past election data (2019 & 2024)
* Perform data cleaning and preprocessing
* Apply feature engineering
* Train a machine learning model
* Evaluate predictions using metrics & visualization

---

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

---

## 📂 Dataset

* 2019 Election Results
* 2024 Election Results

---

## ⚙️ Features Used

* Previous Max Vote Share
* Voter Turnout
* Incumbency
* Urban Percentage

---

## 🤖 Model Used

* Random Forest Classifier

---

## 📊 Results

* Accuracy Score
* Confusion Matrix
* Classification Report

---

## 📈 Visualizations

* Confusion Matrix Heatmap
* Accuracy Bar Chart
* Feature Importance Graph
* ML Pipeline Flow Diagram

---

## 🚀 How to Run

```bash
pip install -r requirements.txt
python main.py
```
