# Indian-Election-Prediction
Election winner prediction using Random Forest

## Overview
This project predicts election winners using Random Forest based on historical Indian election data.

## Features
- Previous Vote Share
- Turnout
- Incumbency
- Urban Percentage

## Model
Random Forest Classifier

## Accuracy
~90%+

## How to Run
1. Upload dataset
2. Run:
   python election_prediction_rf.py
